CODE THE DREAM: Final Project Scope

Project: MixIT

Description(Scope): A music entry and song shuffling web application that allows the user to enter new songs, search songs, and shuffle songs to pick music to play on a musical instrument.

Features:
Enter Song (Title, Artist, Key Signature, BPM[If Available])
View list of songs entered
Search entry by (Title or Artist)
Pick a Random Song (Entry)
User Favorite (# of Plays/Tally for top favorites)

API Usage
theaudiodb - Free API (ClientID & Client_Key needed)
Houndify - [Optional: For song searches using Speech-to-Text]
GetSongBPM - [Alternative: For Song/BPM/Key searches]


Installation Instructions:

Command Prompt(Local) 
1) git clone https://github.com/DragonFruit8/MixIT.git
2) cd ./Folder_Name
3) npm install
4) npm run dev
